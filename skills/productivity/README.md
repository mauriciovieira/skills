# Productivity

General workflow tools, not code-specific.

- **[grill-me](./grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[grilling](./grilling/SKILL.md)** — Interview the user relentlessly about a plan, decision, or idea until every branch of the decision tree is resolved. Ships [`grill-stop`](./grilling/hooks/README.md), an opt-in Stop hook that triggers the same interview automatically after any turn that wrote code.
- **[handin](./handin/SKILL.md)** - Load the newest `*-handoff.md` from the current directory into a fresh session, delete it, and check the live state against it before doing anything.
- **[handoff](./handoff/SKILL.md)** - Write the whole session (goal, state, decisions, changes, facts, open questions, next steps) to `YYYYMMDDHHMM-handoff.md` in the current directory, git-excluded, for `/handin` to pick up.
- **[teach](./teach/SKILL.md)** — Teach the user a new skill or concept over multiple sessions, using the current directory as a stateful teaching workspace.
- **[writing-great-skills](./writing-great-skills/SKILL.md)** — Reference for writing and editing skills well: the vocabulary and principles that make a skill predictable.
