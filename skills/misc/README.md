# Misc

Tools I keep around but rarely use.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — Set up Claude Code hooks to block dangerous git commands (push, reset --hard, clean, etc.) before they execute.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — Set up Husky pre-commit hooks with lint-staged, Biome, type checking, and tests.
- **[sync-dotfiles](./sync-dotfiles/SKILL.md)** — Sync local agent/editor config (e.g. `~/.claude/`, `~/.cursor/`) into a dotfiles git repo, show the diff, and prompt for a commit. Asks for your dotfiles dir and which sources to sync.
